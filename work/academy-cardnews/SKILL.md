# 원장님의 카드뉴스

사용자가 전달한 생각으로 곧바로 한국어 초안을 만든다. 요청에 맞춰 장수를 정하되 보통 표지, 구체적인 설명이나 실천 단계, 마무리로 3~6장을 구성한다. 표지에는 독자가 알아볼 장면이나 질문을 담고 각 본문은 한 가지만 말한다. 공지라면 주어진 날짜와 준비물을 정확히 보존한다. 교육 조언에 가상의 학생 사례나 학원의 실적, 일정, 연락처를 지어내지 않는다. 개인 경험은 사용자가 말한 범위에서만 쓴다.

중간 작업 폴더에 UTF-8 JSON 파일 `카드뉴스-주제.cardnews`를 만든다. 아래 구조에서 title은 전체 작업 제목, 각 장의 title과 body는 실제 게시 문구다. 제목은 약 24자, 본문은 약 80자가 읽기 좋다. topic에는 입력 원문을 보존한다. cards는 1~20장이다. 본문은 빈 문자열일 수 있다. 캡션은 장별 문구를 기반으로 편집기에서 생성한다.

```json
{"version":1,"title":"오답을 다시 보는 시간","topic":"오답노트를 부담 없이 시작하는 법","cards":[{"title":"틀린 문제 한 개부터","body":"오늘 틀린 문제 중 다시 보고 싶은 하나를 골라 보세요."}]}
```

기존 초안을 고치는 요청은 지정한 장과 문구만 변경한다. 기존 파일의 brand, color, logo, photo 등 사용자가 정한 필드를 보존하고 새 파일명으로 저장한다. 새 초안에서는 학원명과 색을 지정받았을 때만 brand와 color(#RRGGBB)를 포함한다. 첫 장이 표지이며 마지막 장이 마무리다.

scripts/make_editor.py에 초안 경로와 새 HTML 출력 경로를 순서대로 전달한다. 표준 Python으로 실행하면 assets/studio.html에 원고가 들어간 편집본이 만들어진다. 파일명이 겹치면 새 이름을 쓴다. 생성한 HTML 파일을 다운로드 링크로 전달하고 “파일을 열어 문구를 고친 뒤 ‘인스타용 저장’을 누르세요”라고 안내한다. 사용자가 로컬에서 열기를 요청했으면 해당 파일을 기본 브라우저에서 연다. HTML 출력이 제한된 세션에서는 .cardnews 초안 파일을 내려주고 소식공방의 ‘열기’로 가져오도록 안내한다. 파일을 만들 수 없으면 편집기의 ‘새로 만들기 → ChatGPT가 준 초안 붙여넣기’에 넣을 JSON을 코드 블록 하나로 전달한다.

사용자가 완성된 카드를 인스타그램에 올려 달라고 명시하면 연결된 Chrome과 로컬 사진 파일을 사용한다. 게시할 계정과 편집본을 식별하고, 해당 내보내기의 01.png부터 마지막 PNG까지 번호순으로 한 게시물에 넣는다. 게시글.txt 또는 사용자가 지정한 캡션을 사용한다. 미리보기에서 장수, 첫 장, 순서와 4:5 구도를 확인한다. “준비해 줘”는 게시 전 화면까지, “게시해 줘”는 게시와 프로필에서의 확인까지 진행한다. 계정이나 결과물이 모호한 경우 그 항목만 확인한다. 게시물 링크는 게시 후 실제로 확인한 주소를 전달한다.
