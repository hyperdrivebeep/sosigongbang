# 소식공방 설계와 검증

2026년 11월 21일 Windows 64비트 환경에서 검증했다.

## 원장님의 작업

학부모에게 전할 생각은 이미 있지만 카드마다 문구를 다시 쓰고 배치하는 데 시간을 쓰기 어려운 원장님을 기준으로 설계했다. AI 사용 경험이 적다는 요청을 반영해 첫 작업에 모델명, 프롬프트 양식, API 키를 요구하지 않는다. 연령이나 성별로 선호 색을 추정하지 않고 학원 색과 로고를 직접 고르게 했다.

| 필요한 일 | 구현한 동작 |
|---|---|
| 주제만 말해도 시작하기 | 새 카드뉴스에 메모 한 줄을 쓰고 ChatGPT로 초안 만들기를 누른다. |
| 학원의 말투 지키기 | 장마다 제목과 본문을 고친다. ‘처음 적은 메모 보기’로 원문을 확인한다. |
| 디자인 반복 줄이기 | 학원명·색·로고를 모든 장에 적용한다. ‘다음에도 이 디자인 사용’으로 보관한다. |
| 실수 고치기 | 장 추가·순서 이동·삭제·되돌리기, 글 넘침 표시, 기기 임시 저장, 파일 재열기를 지원한다. |
| 게시 준비 끝내기 | 번호 순서 PNG, 게시글 문구, 편집 원본을 한 번에 저장한다. |

원문에서 반복 입력과 글상자 크기 조절의 부담, 문단별 자동 배치, 사진 붙여넣기, 포인트 색 활용을 확인했다. 이 제작기는 사진과 글을 담은 정적 캐러셀에 맞췄다. [사용자가 준 레퍼런스](https://m.blog.naver.com/PostView.naver?blogId=lmyjmwl&logNo=224418938730)

## 계정과 실행 방식

Start.cmd가 함께 제공된 Node.js로 PC 내부의 편집기를 실행한다. Chrome이 설치되어 있으면 앱 창으로 열린다. 학원 계정의 Sign in with ChatGPT 연결은 Duvi의 구현을 바탕으로 만들었다. 앱 이름, 설치 식별자, Windows 암호화 저장소는 소식공방 전용이다. 모델 목록은 연결한 계정에서 받아 온다. 초안을 요청하면 메모를 OpenAI에 보내고 완료된 응답을 카드에 채운다. 편집본과 이미지 파일은 PC에서 생성한다. 연결 가능 여부와 사용량은 실제 계정에 부여된 권한을 따른다. [OpenAI 공식 연결 안내](https://developers.openai.com/cookbook/articles/sign-in-with-chatgpt)

## 단계별 QA

| 단계 | 확인한 결과 |
|---|---|
| 실제 계정 연결 | Chrome에서 OpenAI가 소식공방 이름을 표시했다. 사용자가 직접 동의한 뒤 편집기에 ‘ChatGPT 플랜 사용 중’이 표시됐다. |
| 실제 주제 생성 | 시험 전날 틀렸던 문제 한 개를 다시 풀자는 메모와 ‘아이와 나눌 질문, 딱 3장’ 요청을 보냈다. 세 장이 생성됐고 마지막 제목에 질문이 들어갔다. |
| Chrome 편집 | 별도 연습 원고에서 표지 본문과 학원 색을 수정했다. 실제 다운로드한 원본 JSON에서 수정 문장과 색상값을 대조했다. |
| 디자인과 구조 | 별도 브라우저 QA에서 로고와 사진 선택, 브랜드 기억, 장 추가·이동·삭제·복구, 편집본 재열기와 새로고침 복원을 확인했다. |
| 내보내기 | Chrome 다운로드 폴더의 실제 AI 결과 ZIP을 열어 무결성과 PNG 세 장의 1080×1350 크기를 검사했다. 게시글과 편집 원본도 확인했다. |
| 예외와 계정 보관 | 잘못된 초안과 글 넘침에서 기존 작업이 유지됐다. 별도 테스트 계정 데이터로 서명 검증, 플랜 동의 여부, 암호화 저장·복원, 로그아웃을 시험했다. |
| 스킬 | 스킬 검증기를 통과했다. 제공 ZIP에서 스크립트와 템플릿을 꺼내 편집본 생성도 시험했다. ChatGPT 계정의 스킬 업로드·설치 절차는 별도다. |

실제 로그인으로 생성된 결과는 ‘예시/시험 전날 게시용’에 있다. 인스타그램 계정에 올리는 동작은 이 QA 범위에 포함하지 않았다. 원장님 본인이 사용성 평가를 한 결과는 아직 없다.

## Chrome 게시 확장 검증

별도의 Chrome 프로필에 배포용 Manifest V3 확장을 로드했다. 실제 제작기 화면과 모의 Instagram 작성 화면으로 자연어 게시 요청, 순서가 유지된 1080×1350 JPEG 네 장 전달, 4:5 선택, 캡션 입력, 준비 취소, 계정 변경 시 게시 중단, 최종 공유 한 번과 완료 표시를 확인했다. 실제 계정으로 공개 게시하는 과정은 원장님 PC에서 처음 운영할 때 확인할 항목이다.
