소식공방  |  학원 원장님을 위한 카드뉴스 제작기

처음 한 번
받은 ZIP 파일 전체를 ‘압축 풀기’ 한 뒤 소식공방 폴더의 Start.cmd를 더블클릭하세요. Windows 64비트용입니다. Chrome이 설치되어 있으면 Chrome 창이 열립니다. 실행에 필요한 Node.js는 폴더에 들어 있습니다.

첫 카드뉴스 만들기
1. ‘새로 만들기’에서 평소 학부모님께 하시던 말을 적으세요.
   예) 시험 전날에는 새 문제보다 틀린 문제 하나를 다시 봤으면 좋겠어요. 학부모님께 전할 카드 세 장으로 만들어 주세요.
2. ‘ChatGPT로 로그인’을 누르세요. OpenAI 화면에서 본인 계정을 선택하고 소식공방의 ChatGPT 플랜 사용에 동의한 뒤 편집기로 돌아오세요. 해당 기능을 지원하는 계정과 인터넷 연결이 필요합니다.
3. ‘ChatGPT로 초안 만들기’를 누르세요. 입력한 메모로 표지와 본문이 만들어집니다.
4. 고칠 장을 선택하고 오른쪽 ‘제목’이나 ‘본문’에 직접 입력하세요. 글이 넘치면 ‘카드 추가’로 나누세요. 장을 옮기거나 삭제한 뒤 ‘되돌리기’로 복구할 수 있습니다.
5. ‘학원 디자인’에서 학원 이름, 색, 로고를 정하세요. ‘다음에도 이 디자인 사용’을 누르면 같은 브라우저에서 새 초안을 만들 때 다시 적용합니다.
6. ‘인스타용 저장’을 누르세요. ZIP에 01번부터 번호를 붙인 1080×1350 사진, 게시글 문구, 편집 원본이 들어갑니다. 파일 선택을 지원하는 브라우저에서는 ‘사진 폴더에 바로 저장’도 사용할 수 있습니다.

다시 고치고 싶을 때
‘편집본 저장’으로 받은 HTML 파일을 더블클릭하세요. 문구와 사진이 함께 열립니다. ZIP 안의 ‘편집 원본.cardnews’는 편집기의 ‘열기’로 불러올 수 있습니다. 같은 브라우저에는 작업을 임시 저장합니다. 다른 PC로 옮길 때는 편집본 파일을 챙기세요.

내 메모와 파일
초안 생성을 누를 때 메모를 OpenAI로 보냅니다. 로고와 사진의 편집·이미지 저장은 이 PC에서 처리합니다. 로그인 정보는 Windows 사용자 계정으로 암호화해 보관합니다. 우측 상단 ‘연결된 계정’에서 사용량을 보거나 로그아웃할 수 있습니다.
인터넷 없이 완성 원고를 배치하려면 ‘소식공방.html’을 열고 ‘새로 만들기 → 내 글 그대로 배치’를 누르세요.

ChatGPT 안에서 시작하고 싶을 때
스킬 업로드가 가능한 계정에서는 ChatGPT의 Plugins → Skills → Create → Upload에서 academy-cardnews.zip을 선택하세요. “학부모님께 읽기 습관을 전하는 카드뉴스를 만들어 줘”처럼 요청하면 원고가 들어간 편집본을 받을 수 있습니다. 스킬을 제공하는 메뉴는 계정 및 워크스페이스 설정에 따라 다릅니다. 소식공방의 Start.cmd는 스킬 업로드 없이도 사용할 수 있습니다.
